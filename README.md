
# AudioLink v1.0.0 – First Release

The first release of AudioLink!

AudioLink lets you stream your Windows PC's system audio to Android devices over your local Wi-Fi network.

### Windows Desktop
- Connect Android devices over local Wi-Fi.
- Stream system audio to connected devices.
- View and manage connected devices.
- Disconnect or block devices.

### Android App
- Receive live audio from your Windows PC.
- Connect over your local Wi-Fi network.
- Listen to your PC audio on your phone.

### Downloads
- **Windows:** Download `AudioLink-Setup-1.0.0.exe`
- **Android:** Download `AudioLink-Android-1.0.0.apk`

### Installation
1. Download the appropriate file.
2. Install the Windows application on your PC.
3. Install the Android APK on your phone.
4. Connect both devices to the same Wi-Fi network.
5. Start AudioLink and connect your devices.
